# ============================================================================
#  resources.txt - Manifest fuer Fremd-Ressourcen (aktiv: Qbox)
# ============================================================================
#
#  Uebersetzung des offiziellen txAdmin-Rezepts von Qbox:
#    https://github.com/Qbox-project/txAdminRecipe  (qbox.yaml, Commit a4be9fc
#    vom 09.07.2026). Quellen, Branches und Versionen wie im Rezept.
#    Abweichungen: docs/frameworks.md, Abschnitt "Abweichungen vom Rezept".
#
#  Gelesen von scripts/windows/install-resources.ps1 und
#  scripts/linux/install-resources.sh. Alles landet unter server-data/resources/.
#  cfx-server-data (mapmanager, spawnmanager, baseevents ...) installieren die
#  Skripte selbst nach [cfx-default], das steht nicht hier.
#
#  Format (ein Eintrag pro Zeile, Felder durch Leerzeichen getrennt):
#
#    git <ziel> <git-url> [ref]
#        git clone --depth 1 [--branch ref]. Mit --update / -Update: git pull --ff-only.
#
#    zip <ziel> <url>
#        Herunterladen und entpacken. Hat das Archiv genau EINEN Oberordner,
#        wird dessen Inhalt zu <ziel>. --update aendert zip-Ziele nicht, nur --force.
#
#    copy <quelle> <ziel>
#        Kopiert eine Datei oder einen Ordner aus einer weiter oben installierten
#        Zeile ueber eine Datei bzw. einen Ordner einer anderen Ressource.
#        Beide Pfade relativ zu server-data/resources/. Laeuft bei JEDEM Aufruf:
#        Dateien werden nur bei Unterschieden geschrieben, Ordner komplett ersetzt.
#        Eigene Aenderungen am Ziel gehen dabei verloren.
#
#  <ziel> darf Kategorie-Ordner in eckigen Klammern enthalten. 'ensure [qbx]' in
#  server.cfg startet alles unter einem Ordner [qbx], auch innerhalb von [vendor].
#  Ordner mit '.' am Anfang (hier [vendor]/.sources) ignoriert FXServer: dort
#  liegen Quell-Repos, die selbst keine Ressourcen sind.
#
#  Regeln:
#    - Zeilen mit '#' am Anfang und Leerzeilen werden ignoriert.
#    - Reihenfolge zaehlt fuer copy: Quelle und Zielordner muessen weiter oben stehen
#      (install-resources --check prueft das).
#    - Vorhandene git/zip-Ziele werden uebersprungen, ausser mit --update / -Update
#      (nur git) oder --force / -Force.
#    - [vendor]/ und [cfx-default]/ sind in .gitignore, nur diese Datei ist in Git.
#    - ensure-Zeilen stehen in server.cfg, SQL-Dateien in database.txt.
#
#  Andere Frameworks (ESX Legacy, QBCore): docs/frameworks.md
# ============================================================================
