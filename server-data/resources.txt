# ============================================================================
#  resources.txt - Manifest für Fremd-Ressourcen (Third Party)
# ============================================================================
#
#  Wird von scripts/windows/install-resources.ps1 und scripts/linux/
#  install-resources.sh gelesen. Alles hier landet unter server-data/resources/.
#
#  Format (ein Eintrag pro Zeile, Felder durch Leerzeichen getrennt):
#
#    git <ziel> <git-url> [ref]
#        git clone --depth 1 [--branch ref] nach server-data/resources/<ziel>
#        Mit --update / -Update: 'git pull --ff-only', falls <ziel> ein Git-Repo ist.
#
#    zip <ziel> <url>
#        Archiv herunterladen und entpacken. Hat das Archiv genau EINEN
#        Ordner auf oberster Ebene, wird dessen INHALT zu <ziel> (so sind die
#        Release-Zips von oxmysql und ox_lib gebaut). Sonst landet alles
#        direkt in <ziel>.
#
#  <ziel> ist relativ zu server-data/resources/ und darf Kategorie-Ordner in
#  eckigen Klammern enthalten, z. B. [vendor]/oxmysql. FXServer durchsucht
#  Klammer-Ordner rekursiv, der Ressourcenname ist immer der letzte Ordnername.
#
#  Regeln:
#    - Zeilen, die mit '#' beginnen, und Leerzeilen werden ignoriert.
#    - Vorhandene Ziele werden übersprungen, außer mit --update / -Update
#      (nur git) oder --force / -Force (neu herunterladen bzw. neu klonen).
#    - Alles unter [vendor]/ und [cfx-default]/ ist in .gitignore, nur diese
#      Manifest-Datei wird committet.
#    - Nach der Installation die passenden 'ensure'-Zeilen in server.cfg
#      einkommentieren. Reihenfolge: oxmysql -> ox_lib -> Framework.
#
#  Zum Aktivieren eines Blocks einfach das führende '#' entfernen.
# ============================================================================

#  Stellt auch 'mysql-async' und 'ghmattimysql' bereit.
# ----------------------------------------------------------------------------
