# ============================================================================
#  database.txt - SQL-Dateien fuer die Datenbank, in Import-Reihenfolge
# ============================================================================
#
#  Gelesen von scripts/linux/setup-database.sh und scripts/windows/setup-database.ps1.
#  Eine SQL-Datei pro Zeile, Pfad relativ zu server-data/resources/, immer mit '/'.
#  Leerzeilen und Zeilen mit '#' am Anfang werden ignoriert.
#  Erlaubt im Pfad: A-Z a-z 0-9 . _ - [ ] /  (keine Leerzeichen), Endung .sql,
#  keine '.'- oder '..'-Segmente.
#
#  Optional nach dem Pfad, durch ein Leerzeichen getrennt: rerun
#    Nur fuer Dateien, die gefahrlos mehrfach laufen koennen (nur
#    CREATE TABLE IF NOT EXISTS, ADD COLUMN IF NOT EXISTS usw.). Aendert sich eine
#    solche Datei (z. B. neue Spalte nach einem Qbox-Update), wird sie automatisch
#    erneut ausgefuehrt.
#
#  Reihenfolge wie die query_database-Schritte im offiziellen Qbox-Rezept.
#  Die Dateien kommen aus resources.txt, also zuerst die Ressourcen installieren.
#
#  So funktioniert der Import:
#    - Jede Datei wird einmal importiert. Die Tabelle repo_sql_imports in der
#      Datenbank merkt sich Pfad, sha256 und Zeitpunkt.
#    - Neue Zeilen werden beim naechsten Lauf importiert (auch durch deploy.sh).
#    - Aendert sich eine schon importierte Datei OHNE rerun, gibt es nur eine
#      Warnung. Sie wird NICHT erneut ausgefuehrt.
#    - Datenbank schon mit dem txAdmin-Rezept eingerichtet? Einmal
#      --mark-applied bzw. -MarkApplied ausfuehren, siehe docs/datenbank.md.
#
#  Neue Zeilen nur ANHAENGEN. Vorhandene nicht umsortieren oder umbenennen:
#  ein geaenderter Pfad gilt als neue Datei und wuerde erneut importiert.
# ============================================================================
